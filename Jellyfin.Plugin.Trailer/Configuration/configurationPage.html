Trailer Plugin — Настройки

Плагин добавляет кнопку Трейлер на страницу фильма. Трейлер можно смотреть прямо внутри Jellyfin или открывать на YouTube.

Режим воспроизведения

Встроенный плеер — трейлер воспроизводится в наложении поверх интерфейса без ухода с сайта. Новая вкладка — открывает YouTube в браузере.

TMDb

Получить ключ: themoviedb.org/settings/api. Используется для поиска трейлеров на YouTube.

Kinopoisk (запасной источник)

Используется только если TMDb не вернул результат.
Бесплатный токен: kinopoiskapiunofficial.tech. Внимание: неофициальный API, работоспособность не гарантирована.

Кэширование

Результаты хранятся в памяти. 0 — отключить кэш. При перезапуске Jellyfin кэш сбрасывается.

Подключение кнопки в интерфейс

Кнопка Трейлер добавляется через JavaScript-файл. Выберите способ подключения в зависимости от вашей установки Jellyfin.

Способ 1 — файл custom.js (рекомендуется)
Создайте файл custom.js в папке веб-интерфейса Jellyfin и вставьте в него содержимое ниже. Jellyfin загружает этот файл автоматически.

Пути к файлу:
  • Docker: /jellyfin/jellyfin-web/custom.js (или смонтированная папка)
  • Linux (apt/rpm): /usr/share/jellyfin/web/custom.js
  • Windows: C:\Program Files\Jellyfin\Server\jellyfin-web\custom.js
