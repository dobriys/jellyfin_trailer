Trailer Plugin — Настройки

Плагин добавляет кнопку Трейлер на страницу фильма. По клику открывается список найденных на YouTube трейлеров, выбранный воспроизводится прямо внутри Jellyfin.

YouTube Data API

Требуется бесплатный YouTube Data API v3 ключ для поиска трейлеров.

Получить бесплатно: Google Cloud Console → Включить «YouTube Data API v3» → Credentials → Create API Key.

Подключение кнопки «Трейлер» в интерфейс

Кнопка добавляется через JavaScript. Создайте файл custom.js в папке веб-интерфейса Jellyfin или настройте Nginx.

Способ 1 — файл custom.js (рекомендуется)

Создайте файл по одному из путей:
  • linuxserver/docker: /usr/share/jellyfin/web/custom.js
  • Linux (apt/rpm): /usr/share/jellyfin/web/custom.js
  • Windows: C:\Program Files\Jellyfin\Server\jellyfin-web\custom.js
