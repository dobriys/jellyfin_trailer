Trailer Plugin — Настройки

Плагин добавляет кнопку Трейлер на страницу фильма. Трейлер можно смотреть прямо внутри Jellyfin или открывать на YouTube.

Kinopoisk

Бесплатный токен: kinopoiskapiunofficial.tech. Регистрация → личный кабинет → скопировать API KEY.

YouTube канал с трейлерами

Если Kinopoisk не нашёл YouTube-трейлер, плагин ищет на указанном YouTube-канале. Требуется бесплатный YouTube Data API v3 ключ.

Получить бесплатно: Google Cloud Console → Включить «YouTube Data API v3» → Credentials → Create API Key.
Handle канала, например @KinomanTrailers. Плагин ищет «название фильма трейлер год» на этом канале.

Режим воспроизведения

Встроенный плеер — трейлер воспроизводится в наложении поверх интерфейса без ухода с сайта. Новая вкладка — открывает YouTube.

TMDb (необязательно)

Если TMDb API Key не заполнен — поиск идёт сразу через Kinopoisk.

Получить: themoviedb.org/settings/api.

Кэширование

Результаты хранятся в памяти. 0 — отключить кэш. При перезапуске Jellyfin кэш сбрасывается.

Подключение кнопки «Трейлер» в интерфейс

Кнопка добавляется через JavaScript. Создайте файл custom.js в папке веб-интерфейса Jellyfin или настройте Nginx.

Способ 1 — файл custom.js (рекомендуется)

Создайте файл по одному из путей:
  • linuxserver/docker: /usr/share/jellyfin/web/custom.js
  • Linux (apt/rpm): /usr/share/jellyfin/web/custom.js
  • Windows: C:\Program Files\Jellyfin\Server\jellyfin-web\custom.js
